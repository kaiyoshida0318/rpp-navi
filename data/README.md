# data — 実データと参照資料

2026年5〜8月の実データ一式です。ツールの動作確認・バックテスト・検証スクリプトで使います。

| ファイル | 中身 |
|---|---|
| `rpp-raw-2026-05to08.zip` | RPP元データ一式（商品別/KW別/全体レポート、売上CSV、CPC設定）。5/1〜8/26の115日分 |
| `events-2026-05to08.txt` | イベント日程（マラソン／スーパーSALE の開始・終了日時） |
| `watchlog-sample.xlsx` | 当日時間別RPP記録のサンプル（38件）。灰色セル＝予算上限到達 |
| `orderhour.xlsx` | 受注日_1時間単位集計（店舗全体の注文。RPPの時間別CVRではない） |
| `calref-2026-05〜08.png` | 実カレンダー画像4枚。取込結果の**照合の正解**として使う |
| `ascii/` | ↑と同じ中身のASCII名コピー。`tests/` の検証スクリプトはこちらを参照します |

## 取込方法

ツールの**取込**タブに、以下の4つをまとめてドラッグ&ドロップしてください。

```
rpp-raw-2026-05to08.zip
events-2026-05to08.txt
watchlog-sample.xlsx
orderhour.xlsx
```

正しく取り込めると、ログの最後がこうなります。

```
── 完了：商品別115 / KW別115 / 全体115 / 売上123 / CPC設定2 /
        当日記録1 / 時間帯1 / イベント8 / スキップ1 / エラー0 ──
```

欠測は `2026-06-23` `2026-06-25` `2026-06-29` の3日です（0ではなく「未観測」として扱われます）。

## 注意

- `rpp-raw-...zip` の中には**入れ子のZIPと古いエクスポート**が混ざっています。
  ツールは各ファイルの `実行日時:` を読んで古い方を拒否します（同じ日付で新旧が混在するため）。
- 元データの文字コードは CP932 です。ツール側で自動判定しています。
- ⚠️ 実店舗の売上金額・広告費・出稿キーワード・商品管理番号が含まれます。
