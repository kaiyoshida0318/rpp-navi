# tests — 検証スクリプト

Playwright で `index.html` を実際のブラウザで開き、`data/ascii/` の実データを
取り込ませて結果を確認します。ソースを変更したら実行してください。

## 準備

```bash
npm i playwright
npx playwright install chromium
```

## 実行

```bash
bash src/build.sh      # 先に index.html を作り直す
cd tests
node t3.js             # 通し確認：取込115日 → 8タブ全描画 → カレンダー画像との突合
node vfy.js            # 当日判定8ケース（clickHot を含む）
node bf.js             # 「後日まとめて入力」モード
node q3.js             # 上限到達日のバイアス方向、上限超過提案の抑制
```

## 数字が変わったら

**期待値と違う数字が出たら、期待値の方を書き換える前に原因を調べてください。**
特に捕捉率 85/88/88 と誤警報率 14% は、朝の警戒ルール v1
（前日20円実績 ≥ ¥30,000 **または** 前日20円ROAS < 225%）の性能そのものです。
ここが動いたということは、判定ロジックか取込のどちらかが変わっています。

背景は [`../docs/handover.md`](../docs/handover.md) の §4・§5 を参照。
